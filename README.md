# Vimlesh OS

A minimalist personal operating system / habit tracker inspired by the UI references provided in the conversation.

## Features
- Daily habit completion
- Percentage progress ring
- Current streak + best streak
- Monthly consistency calendar
- 14-day progress chart
- Add custom habits
- LocalStorage persistence
- Offline-capable PWA shell
- Responsive mobile-first UI

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will give you the live URL.

## Important
This is a frontend-only app. Data is stored locally in the browser. No login or backend is included.
