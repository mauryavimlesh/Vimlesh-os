# VIMLESH OS
A free, local-first personal routine, habit, calendar, workout and progress tracker inspired by the supplied references.

## Run
Open `index.html` in a browser.

## Install like an app
For full PWA installation/offline service-worker behavior, upload this folder to any free static host such as GitHub Pages, then open the URL on Android Chrome and choose **Add to Home screen / Install app**.

## Data
Data is stored in browser localStorage on the device. Use **More → Export JSON** for backup.
